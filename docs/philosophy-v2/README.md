# Philosophy - V2
## Introduction
> **Key source**: [`the-milvus-way`, **github.com**](https://github.com/mistermilvusmigrans/the-milvus-way)

Philosophy V2 is primarily focused on morality, drawing its metaphysics and epistemology from [Philosophy V1](../philosophy-v1/). Philosophy V2 retains the egoistic orientation of [Ethics, Philosophy V1](../philosophy-v1/ethics/), but instead of setting its standard of value as life, it asks the question: what would morality look like if truth-orientation was the only moral axiom?

The purpose of this project is to see whether and to what extent an epistemological commitment to reality translates into ethical commitments. This project exists primarily to interrogate and explore whether there is any fundamental difference between "truth-orientation" and morality, and whether and to what extent seeking the truth can ever produce a coherent moral stance on its own.
